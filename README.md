# Banco-de-Dados-de-Objeto---Sistema-de-Cat-logo-de-M-sicas
1.1 Finalidade do Banco de Dados O banco de dados de objeto proposto tem como finalidade gerenciar um sistema de catálogo digital de músicas, permitindo o armazenamento, organização e recuperação de informações sobre artistas, álbuns e faixas musicais.
